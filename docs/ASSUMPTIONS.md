# Assumptions and decisions

These decisions were made while bootstrapping the repo without stopping to ask (CLAUDE.md §14).
Change any of them freely and update this file.

## Hardware and firmware

- **Servo PWM firmware.** Option B in `firmware/GRBL_SETUP.md` patches GRBL 1.1h. It sets the
  Timer2 prescaler to 1/1024 (≈61 Hz frame; SG90s accept 50–60 Hz) and maps
  `S $31…$30 → OCR2A 8…38` (≈0.5–2.4 ms) via `SPINDLE_PWM_MIN_VALUE` / `SPINDLE_PWM_MAX_VALUE`.
  The edits were written from GRBL 1.1h's source layout, not compiled here. Check the names in
  your copy. The default pen commands (`M3 S30` / `M3 S90`) are placeholders until you
  calibrate.
- **Homing.** X/Y switches sit at the minimum (front-left) ends. GRBL is built with
  `HOMING_CYCLE_0 = X|Y` (there is no Z switch) and `HOMING_FORCE_SET_ORIGIN`, so the machine
  origin is (0, 0) at home with positive coordinates, matching the generated G-code.
  `$23=3` is a starting value.
- **Soft limits** (`$20=1`) and **hard limits** (`$21=1`) are on in the starting settings.
  Noisy switches may need `$21=0`.
- **Time estimate.** `motion.accel_mm_s2` (500) mirrors `$120/$121` and is used only for time
  estimates. G0 is estimated at `travel_feed_mm_min`, which should equal `$110/$111`.
- **BOM prices** are rough Indian retail ranges for late 2026 and vary a lot by seller.

## Software

- **Python 3.10–3.12** as in the spec. `requirements*.txt` are *universal* locks
  (`uv pip compile --universal`) with markers, because current numpy/scipy/scikit-image no
  longer support 3.10.
- **Hershey font** from the `Hershey-Fonts` PyPI package (public-domain Hershey data, font
  `futural`), so `plotter/fonts/` isn't needed. Characters without a glyph are drawn as `?`.
  Typographic quotes and dashes are mapped to ASCII.
- **Text jitter** is applied per glyph: scale about the glyph origin, rotation, and baseline
  offset. The worst-case growth is reserved inside the margins, so text never crosses them.
- **Path ordering** starts from the machine's home position expressed in page coordinates
  (`Config.home_in_page_mm`), not page (0, 0). This is where the pen really is before the
  first stroke. `order_paths` still defaults to (0, 0) when called directly.
- **Outline mode** follows the spec (Canny + `findContours`) but skips pixels already drawn by
  another contour, so the two sides of a 1-px edge are not plotted twice.
- **Lineart tracing** removes redundant L-corner pixels and extends strokes to the junction
  centroid, so strokes meet exactly and `join_paths` can merge them.
- **Hatch** levels are equal-width brightness bins after min-max normalisation. The lightest
  level gets no hatching.
- **Perspective.** A detected quad that is wider than tall is rotated 90° so the output is
  always portrait. That can't tell which way is up, so photograph pages upright.
- **OCR.** The SDK's built-in retries (exponential backoff on 429/5xx/connection errors,
  `max_retries` from config) are used rather than a hand-rolled loop. Images are downscaled to
  `ai.max_image_px` (2000 px long side) and sent as JPEG. `auto` falls back to Tesseract on
  any AI error, including refusals. The model is never hardcoded (`AI_MODEL`); the example in
  `.env.example` and the error messages suggests `claude-opus-5-5`.
- **`FakeGrbl`** lives in `plotter/fake_grbl.py` (not in `grbl.py`) to keep modules under
  ~400 lines. `plotter send --dry-run` streams through it, so the dry run exercises the real
  character-counting code without touching a port.
- **Error handling while streaming.** On `error:N` the host stops sending, waits for the lines
  already in GRBL's buffer, then lifts the pen. After a reset or an alarm it does not try,
  because GRBL has flushed its buffer and may lock G-code.
- **Confirmations.** `send`, `home` and `jog` ask before moving the real machine (skip with
  `--yes`). `pen` and `unlock` don't ask. Every machine command has `--dry-run`.
- **Additional exception** `GcodeError` (base of `OutOfBoundsError`) for unsafe or malformed
  G-code that isn't a bounds problem.
- **Extra config keys:** `machine.connect_wait_s`, `machine.response_timeout_s`,
  `motion.accel_mm_s2`, `paths.two_opt_max_paths`, `ai.max_image_px` (documented in
  CLAUDE.md §6).
- **Samples** are synthetic (`scripts/make_samples.py`): no personal photos are committed.
  `samples/calibration_square.gcode` and `samples/origin_mark.gcode` are generated by
  `scripts/make_calibration.py`.
